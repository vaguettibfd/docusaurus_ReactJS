# ReactJS Básico

Bem-vindo ao **ReactJS Básico**! 🚀

Este e-book foi desenvolvido como um material introdutório e prático para apoiar
a aprendizagem do **ReactJS**, apresentando gradualmente os principais conceitos
necessários para a construção de interfaces Web baseadas em componentes.

Ao longo do material, você encontrará explicações conceituais acompanhadas de
**exemplos de código**, comentários e exercícios que permitem compreender não
apenas **como escrever uma aplicação React**, mas também como seus diferentes
elementos se relacionam.

## 🎯 Objetivos de aprendizagem

Ao concluir este material, espera-se que você seja capaz de:

- compreender a organização básica de um projeto ReactJS;
- identificar o papel dos principais arquivos de uma aplicação;
- compreender o funcionamento do ponto de montagem da aplicação;
- utilizar **JSX** para construção de interfaces;
- criar e reutilizar **componentes**;
- compreender a relação entre componentes pai e filho;
- utilizar **props** para passagem de informações entre componentes;
- trabalhar com componentes funcionais;
- reconhecer a estrutura de componentes baseados em classe;
- organizar uma aplicação por meio da componentização.
