#  📘 Cadastro de Pessoas com Ant Design

No capítulo anterior, conhecemos o **Ant Design (AntD)** e utilizamos alguns de
seus componentes para construir uma interface de Login.

Agora avançaremos para uma aplicação mais completa: um **cadastro de pessoas**.

A aplicação permitirá cadastrar dois tipos de pessoa:

```text
Pessoa
  │
  ├── Pessoa Física (PF)
  │
  └── Pessoa Jurídica (PJ)
```

Além dos dados principais, o cadastro será organizado em diferentes partes:

```text
Cadastro de Pessoa
       │
       ├── Dados principais
       │
       ├── Endereço
       │
       └── Telefones
```

Neste capítulo utilizaremos recursos importantes do Ant Design, como
`Form`, `Form.Item`, `Row`, `Col`, `Input`, `DatePicker`, `Select`, `Button`,
`Space`, `List` e `message`.

O principal avanço será a utilização do **sistema de formulários e validação
do Ant Design**.

:::info Objetivos do capítulo

Ao final deste capítulo, você deverá ser capaz de:

- construir formulários utilizando `Form` e `Form.Item`;
- criar regras de validação declarativas;
- organizar formulários em componentes menores;
- utilizar campos diferentes para Pessoa Física e Pessoa Jurídica;
- construir layouts utilizando `Row` e `Col`;
- utilizar campos aninhados em formulários;
- adicionar elementos dinamicamente a uma lista;
- apresentar feedback utilizando `message`;
- complementar o Ant Design utilizando CSS.

:::

# Estrutura da aplicação

Para evitar a criação de um componente muito grande, dividiremos o cadastro
em diferentes componentes.

A estrutura principal será:

```text
src/
│
├── App.jsx
│
└── components/
    └── cadastrapessoa/
        ├── PessoaForm.jsx
        ├── EnderecoForm.jsx
        ├── TelefoneList.jsx
        └── pessoaform.css
```

Cada arquivo possuirá uma responsabilidade:

```text
PessoaForm.jsx
     │
     ├── formulário principal
     ├── dados da pessoa
     ├── seleção PF/PJ
     └── integração dos demais componentes

EnderecoForm.jsx
     │
     └── dados de endereço

TelefoneList.jsx
     │
     └── gerenciamento dos telefones

pessoaform.css
     │
     └── ajustes visuais complementares
```

Essa organização aplica um conceito que já estudamos anteriormente:
**componentização**.

Em vez de concentrarmos toda a aplicação em um único arquivo, distribuímos
responsabilidades entre componentes menores.

# Formulários com Ant Design

No capítulo anterior utilizamos campos isolados do Ant Design.

Agora utilizaremos:

```jsx
<Form>
```

O componente `Form` permite organizar e controlar diferentes campos de um
formulário.

Dentro dele utilizaremos:

```jsx
<Form.Item>
```

Podemos visualizar:

```text
Form
 │
 ├── Form.Item
 │      └── Input
 │
 ├── Form.Item
 │      └── DatePicker
 │
 ├── Form.Item
 │      └── Select
 │
 └── Form.Item
        └── Button
```

:::info `Form.Item`

`Form.Item` funciona como um container para um campo do formulário.

Ele pode definir informações como:

```text
label
name
rules
```

Isso permite associar o campo a um nome e definir regras de validação.

:::

# Criando uma instância do formulário

Dentro de `PessoaForm`, utilizaremos:

```jsx
const [form] = Form.useForm();
```

Essa instrução cria uma instância do formulário.

Podemos pensar da seguinte forma:

```text
Form.useForm()
      │
      ▼
    form
      │
      ▼
controle do formulário
```

Depois associamos essa instância ao componente:

```jsx
<Form form={form}>
```

Isso permite acessar e manipular os dados do formulário programaticamente.

# Pessoa Física e Pessoa Jurídica

Nosso cadastro trabalhará com dois tipos de pessoa.

Para controlar a opção selecionada utilizaremos:

```jsx
const [tipoPessoa, setTipoPessoa] = useState("PF");
```

Inicialmente:

```text
tipoPessoa = "PF"
```

Quando o usuário selecionar outra opção:

```text
PF
 │
 │ usuário seleciona PJ
 ▼
onChangeTipo()
 │
 ▼
setTipoPessoa("PJ")
 │
 ▼
tipoPessoa = "PJ"
```

Assim, a interface poderá apresentar campos diferentes de acordo com o tipo
selecionado.

---

# Selecionando o tipo de pessoa

Utilizaremos:

```jsx
<Form.Item
  label="Tipo de Pessoa"
  name="tipo"
  initialValue="PF"
  style={{ marginBottom: 10 }}
>

  <Radio.Group onChange={onChangeTipo}>

    <Radio value="PF">
      Pessoa Física
    </Radio>

    <Radio value="PJ">
      Pessoa Jurídica
    </Radio>

  </Radio.Group>

</Form.Item>
```

Temos dois componentes importantes:

```text
Radio.Group
    │
    ├── Radio PF
    └── Radio PJ
```

A propriedade:

```jsx
value="PF"
```

representa Pessoa Física.

Enquanto:

```jsx
value="PJ"
```

representa Pessoa Jurídica.

---

# Evento `onChangeTipo`

Podemos utilizar:

```jsx
const onChangeTipo = (e) => {

  const novoTipo = e.target.value;

  setTipoPessoa(novoTipo);

  form.setFieldValue(
    "tipo",
    novoTipo
  );
};
```

O evento recebido contém a opção selecionada:

```text
e.target.value
       │
       ├── "PF"
       │
       └── "PJ"
```

O estado é atualizado por:

```jsx
setTipoPessoa(novoTipo);
```

E o formulário também recebe o valor:

```jsx
form.setFieldValue(
  "tipo",
  novoTipo
);
```

# Criando campos com `Form.Item`

Vamos observar um campo simples:

```jsx
<Form.Item
  label="Nome"
  name="nome"
  rules={[
    {
      required: true,
      message: "Informe o nome!"
    }
  ]}
>

  <Input
    placeholder="Nome completo ou razão social"
  />

</Form.Item>
```

Temos:

```text
Form.Item
   │
   ├── label
   ├── name
   ├── rules
   │
   └── Input
```

---

# `label`

A propriedade:

```jsx
label="Nome"
```

define o rótulo apresentado para o campo.

Quando utilizamos:

```jsx
<Form layout="vertical">
```

o rótulo aparece acima do campo.

Visualmente:

```text
Nome
┌────────────────────────────┐
│ Nome completo...           │
└────────────────────────────┘
```

---

# `name`

A propriedade:

```jsx
name="nome"
```

identifica o campo dentro do formulário.

Assim, quando o formulário for enviado, poderemos obter uma estrutura
semelhante a:

```text
values
  │
  ├── tipo
  ├── nome
  ├── email
  └── ...
```

Por exemplo:

```jsx
values.nome
```

permite acessar o valor associado ao campo `nome`.

---

# Validação com `rules`

Uma das principais vantagens de `Form.Item` é a possibilidade de declarar
regras de validação.

Observe:

```jsx
rules={[
  {
    required: true,
    message: "Informe o nome!"
  }
]}
```

A propriedade:

```text
required: true
```

indica que o campo é obrigatório.

Enquanto:

```text
message
```

define a mensagem apresentada caso a regra não seja atendida.

O fluxo será:

```text
Usuário envia formulário
          │
          ▼
AntD verifica rules
          │
          ├── campo válido
          │       │
          │       ▼
          │    continua
          │
          └── campo inválido
                  │
                  ▼
            exibe mensagem
```

:::tip Validação declarativa

Observe que não precisamos criar manualmente uma condição como:

```jsx
if (nome === "") {
  ...
}
```

A regra é declarada diretamente no `Form.Item`.

Essa abordagem é chamada de **validação declarativa**.

:::

# Validando o e-mail

Podemos combinar diferentes regras:

```jsx
<Form.Item
  label="Email"
  name="email"
  rules={[
    {
      required: true,
      message: "Informe o e-mail!"
    },
    {
      type: "email",
      message: "Formato de e-mail inválido!"
    }
  ]}
>

  <Input
    placeholder="exemplo@email.com"
  />

</Form.Item>
```

Nesse exemplo temos duas validações:

```text
Regra 1
  │
  └── campo obrigatório

Regra 2
  │
  └── formato de e-mail
```

Assim:

```text
email vazio
    │
    ▼
"Informe o e-mail!"

email com formato inválido
    │
    ▼
"Formato de e-mail inválido!"
```

O formulário utilizará:

```jsx
<Form
  layout="vertical"
  form={form}
  onFinish={onFinish}
>
```

A propriedade:

```jsx
layout="vertical"
```

organiza os campos desta forma:

```text

[________________________]

[________________________]
```

Em vez de posicionar o rótulo ao lado do campo.

# Enviando o formulário com `onFinish`

O Ant Design utiliza:

```jsx
onFinish={onFinish}
```

Quando as validações forem atendidas, a função será executada.

Podemos criar:

```jsx
const onFinish = (values) => {

  console.log(
    "Dados cadastrados:",
    values
  );

  message.success(
    "Cadastro realizado com sucesso!"
  );
};
```

A variável:

```text
values
```

conterá os dados preenchidos no formulário.

O fluxo será:

```text
Usuário
   │
   ▼
preenche formulário
   │
   ▼
clica em cadastrar
   │
   ▼
AntD executa validações
   │
   ├── erro
   │    └── apresenta mensagens
   │
   └── válido
        │
        ▼
     onFinish(values)
        │
        ├── console.log()
        └── message.success()
```

# Utilizando `span`

Observe:

```jsx
<Col span={12}>
```

e:

```jsx
<Col span={6}>
```

Podemos visualizar:

```text
┌──────────────────────────────────────────────┐
│                  Row                         │
├───────────────────────┬───────────┬──────────┤
│       Cidade          │    UF     │ Região   │
│       span=12         │  span=6   │ span=6   │
```


O sistema de Grid do Ant Design utiliza uma divisão em **24 partes**.

Portanto:

```text

span={12} → metade da linha

span={8}  → aproximadamente 1/3

span={6}  → 1/4 da linha
```

:::

# Adicionando um telefone

Podemos criar:

```jsx
function adicionarTelefone() {

  if (!ddd || !numero) {
    return;
  }

  const novoTelefone = {
    ddd,
    numero
  };

  setTelefones([
    ...telefones,
    novoTelefone

  setNumero("");

```

O fluxo será:

```text

      │
      ▼
adicionarTelefone()
      │
      ▼
novoTelefone
      │
      ▼
setTelefones()
      │
      ▼
nova lista
```

Observe:

```jsx
[
  ...telefones,
  novoTelefone
]
```

O operador:

```text

```

mantém os elementos existentes e acrescenta o novo telefone.

# Criando `TelefoneList.jsx`

## `TelefoneList.jsx`

```jsx
import React, { useState } from "react";

import {
  Form,
  Input,
  Button,
  Space,
  List
} from "antd";

export default function TelefoneList() {

  const [ddd, setDdd] = useState("");
  const [numero, setNumero] = useState("");
  const [telefones, setTelefones] = useState([]);

  function adicionarTelefone() {

    if (!ddd || !numero) {
      return;
    }

    const novoTelefone = {
      ddd,
      numero
    };

    setTelefones([
      ...telefones,
      novoTelefone
    ]);

    setDdd("");
    setNumero("");
  }

  return (
    <>
      <h3>Telefones</h3>

      <Space align="baseline">

        <Form.Item label="DDD">

          <Input
            value={ddd}
            onChange={(e) =>
              setDdd(e.target.value)
            }
            maxLength={2}
          />

        </Form.Item>

        <Form.Item label="Número">

          <Input
            value={numero}
            onChange={(e) =>
              setNumero(e.target.value)
            }
            maxLength={9}
          />

        </Form.Item>

        <Button
          onClick={adicionarTelefone}
          type="primary"
        >
          Adicionar
        </Button>

      </Space>

      <List
        size="small"
        bordered
        dataSource={telefones}
        renderItem={(telefone, index) => (

          <List.Item key={index}>

            ({telefone.ddd}) {telefone.numero}

          </List.Item>

        )}
        style={{
          marginTop: 10
        }}
      />

    </>
  );
}
```

# Estrutura básica de `PessoaForm.jsx`

Agora podemos reunir os conceitos principais.

## `PessoaForm.jsx`

```jsx
import React, {
  useEffect,
  useState
} from "react";

import {
  Form,
  Input,
  Button,
  Radio,
  DatePicker,
  message
} from "antd";

import {
  ArrowUpOutlined
} from "@ant-design/icons";

import EnderecoForm from "./EnderecoForm.jsx";
import TelefoneList from "./TelefoneList.jsx";

import "./pessoaform.css";

export default function PessoaForm() {

  const [form] = Form.useForm();

  const [tipoPessoa, setTipoPessoa] =
    useState("PF");

  const [mostrarTopo, setMostrarTopo] =
    useState(false);

  const onChangeTipo = (e) => {

    const novoTipo = e.target.value;

    setTipoPessoa(novoTipo);

    form.setFieldValue(
      "tipo",
      novoTipo
    );
  };

  const onFinish = (values) => {

    console.log(
      "Dados cadastrados:",
      values
    );

    message.success(
      "Cadastro realizado com sucesso!"
    );
  };

  useEffect(() => {

    function verificarRolagem() {

      setMostrarTopo(
        window.scrollY > 200
      );
    }

    window.addEventListener(
      "scroll",
      verificarRolagem
    );

    return () => {

      window.removeEventListener(
        "scroll",
        verificarRolagem
      );
    };

  }, []);

  function voltarAoTopo() {

    window.scrollTo({
      top: 0,
      behavior: "smooth"
    });
  }

  return (
    <main className="main-scroll">

      <div className="form-container">

        <h2>Cadastro de Pessoas</h2>

        <Form
          layout="vertical"
          form={form}
          onFinish={onFinish}
        >

          <Form.Item
            label="Tipo de Pessoa"
            name="tipo"
            initialValue="PF"
            style={{
              marginBottom: 10
            }}
          >

            <Radio.Group
              onChange={onChangeTipo}
            >

              <Radio value="PF">
                Pessoa Física
              </Radio>

              <Radio value="PJ">
                Pessoa Jurídica
              </Radio>

            </Radio.Group>

          </Form.Item>

          <Form.Item
            label={
              tipoPessoa === "PF"
                ? "Nome"
                : "Razão Social"
            }
            name="nome"
            rules={[
              {
                required: true,
                message:
                  "Informe o nome!"
              }
            ]}
          >

            <Input
              placeholder={
                tipoPessoa === "PF"
                  ? "Nome completo"
                  : "Razão social"
              }
            />

          </Form.Item>

          <Form.Item
            label="Email"
            name="email"
            rules={[
              {
                required: true,
                message:
                  "Informe o e-mail!"
              },
              {
                type: "email",
                message:
                  "Formato de e-mail inválido!"
              }
            ]}
          >

            <Input
              placeholder="exemplo@email.com"
            />

          </Form.Item>

          {tipoPessoa === "PF" ? (

            <Form.Item
              label="CPF"
              name="cpf"
              rules={[
                {
                  required: true,
                  message:
                    "Informe o CPF!"
                }
              ]}
            >

              <Input
                placeholder="CPF"
                maxLength={14}
              />

            </Form.Item>

          ) : (

            <Form.Item
              label="CNPJ"
              name="cnpj"
              rules={[
                {
                  required: true,
                  message:
                    "Informe o CNPJ!"
                }
              ]}
            >

              <Input
                placeholder="CNPJ"
                maxLength={18}
              />

            </Form.Item>

          )}

          <Form.Item
            label={
              tipoPessoa === "PF"
                ? "Data de Nascimento"
                : "Data de Fundação"
            }
            name="data"
            rules={[
              {
                required: true,
                message:
                  "Informe a data!"
              }
            ]}
          >

            <DatePicker
              style={{
                width: "100%"
              }}
              format="DD/MM/YYYY"
            />

          </Form.Item>

          <EnderecoForm />

          <TelefoneList />

          <Form.Item>

            <Button
              type="primary"
              htmlType="submit"
              block
              size="large"
            >
              Cadastrar
            </Button>

          </Form.Item>

        </Form>

      </div>

      {mostrarTopo && (

        <button
          className="scroll-top-button"
          onClick={voltarAoTopo}
          aria-label="Voltar ao topo"
        >

          <ArrowUpOutlined />

        </button>

      )}

    </main>
  );
}
```

:::info Sobre o exemplo

`PessoaForm` é responsável pela estrutura principal e delega partes específicas
do cadastro para:

```text
EnderecoForm
TelefoneList
```

Essa divisão reduz a quantidade de responsabilidades concentradas em um único
componente.

:::

# Limpeza do evento

Observe que o `useEffect` retorna:

```jsx
return () => {

  window.removeEventListener(
    "scroll",
    verificarRolagem
  );
};
```

Isso remove o evento quando o componente deixa de ser utilizado.

Podemos representar:

```text
Componente montado
      │
      ▼
addEventListener()
      │
      ▼
evento ativo
      │
      ▼
componente desmontado
      │
      ▼
removeEventListener()
```

:::tip

Ao registrar eventos externos ao React, é importante remover esses eventos
quando eles não forem mais necessários.

# Resumo

Neste capítulo evoluímos de uma interface simples construída com Ant Design
para um **formulário de cadastro composto por diferentes componentes**.

A evolução pode ser representada por:

```text
Componentes React
        │
        ▼
Ant Design
        │
        ▼
Form
        │
        ▼
Form.Item
        │
        ▼
Validação declarativa
        │
        ▼
Formulário dinâmico PF/PJ
        │
        ▼
Subcomponentes
        │
        ├── EnderecoForm
        └── TelefoneList
        │
        ▼
Grid responsivo
        │
        ├── Row
        └── Col
        │
        ▼
Aplicação de cadastro
```

O `PessoaForm` atua como componente principal, enquanto `EnderecoForm` e
`TelefoneList` separam responsabilidades específicas da aplicação.

Também avançamos no uso do Ant Design com:

```text
Form + Form.Item
       │
       └── validação declarativa

Row + Col
       │
       └── organização em Grid

Input + Select + DatePicker
       │
       └── entrada de dados

Space + List
       │
       └── organização e apresentação

Button + message
       │
       └── ação e feedback
```

Essa estrutura permite construir formulários maiores sem abandonar os
princípios estudados desde os primeiros capítulos: **componentização,
reutilização, estado, eventos e separação de responsabilidades**.
