# 📘 Componentes e Estilos (Tailwind)

No capítulo anterior, utilizamos **CSS** para definir a apresentação visual dos
componentes React.

Para cada componente, criamos uma folha de estilos correspondente:

```text
Label.jsx ─────────────► Label.css
LabelTitle.jsx ────────► LabelTitle.css
InputText.jsx ─────────► InputText.css
InputPassword.jsx ─────► InputPassword.css
Button.jsx ────────────► Button.css
Login.jsx ─────────────► Login.css
```

Agora utilizaremos outra abordagem para estilizar a mesma aplicação:
**Tailwind CSS**.

Com Tailwind, grande parte da estilização pode ser realizada diretamente no
JSX utilizando **classes utilitárias**.

Por exemplo, anteriormente poderíamos ter:

```jsx
<button className="btn">
  Logar
</button>
```

e definir sua aparência em outro arquivo:

```css
.btn {
  width: 100%;
  padding: 0.8rem;
  background-color: #0066cc;
  color: white;
}
```

Com Tailwind, essas características podem ser representadas diretamente no
elemento:

```jsx
<button className="w-full px-4 py-2 bg-blue-600 text-white">
  Logar
</button>
```

:::info Tailwind CSS

Tailwind utiliza uma abordagem conhecida como **Utility-First CSS**.

Em vez de criarmos uma classe CSS personalizada para cada elemento, combinamos
classes utilitárias que representam propriedades específicas de estilo.

:::

# Estilizando `Label.jsx`

Começaremos pelo componente utilizado para apresentar os rótulos dos campos.

## `Label.jsx`

```jsx
import React, { useState } from 'react';

export default function Label({ texto }) {

  const [valor] = useState(texto);

  return (
    <label
      className="block text-base font-medium text-gray-800 mb-1"
    >
      {valor}
    </label>
  );
}
```

O funcionamento do componente continua semelhante ao estudado anteriormente.

A novidade está em:

```jsx
className="block text-base font-medium text-gray-800 mb-1"
```

Em vez de criarmos uma classe personalizada em `Label.css`, combinamos
diferentes utilitários.

---

## Entendendo as classes

| Classe | Função |
|---|---|
| `block` | Faz o elemento ocupar a linha como bloco |
| `text-base` | Define o tamanho padrão da fonte |
| `font-medium` | Define peso intermediário para a fonte |
| `text-gray-800` | Define uma tonalidade escura de cinza |
| `mb-1` | Adiciona uma pequena margem inferior |

Podemos decompor:

```text
className="
  block
  text-base
  font-medium
  text-gray-800
  mb-1
"
```

Cada classe possui uma responsabilidade.

# Espaçamento no Tailwind

Nos exemplos anteriores já encontramos:

```text
mb-1
mb-4
```

O prefixo:

```text
m
```

está relacionado a **margin**.

A letra seguinte indica a direção.

```text
mt  → margin-top
mr  → margin-right
mb  → margin-bottom
ml  → margin-left
```

Também encontraremos classes relacionadas a `padding`:

```text
p   → padding
px  → padding horizontal
py  → padding vertical
```

Por exemplo:

```text
px-3
```

adiciona espaçamento interno horizontal.

Enquanto:

```text
py-2
```

adiciona espaçamento interno vertical.

Podemos representar:

```text
          py
           ↓
    ┌──────────────┐
px →│   conteúdo   │← px
    └──────────────┘
           ↑
          py
```

# Estilizando `InputText.jsx`

Agora utilizaremos Tailwind no campo de texto.

Continuaremos com os conceitos estudados anteriormente:

```text
useState
onChange
e.target.value
validação
renderização condicional
```

A novidade será a apresentação visual.

## `InputText.jsx`

```jsx
import React, { useState } from 'react';

export default function InputText({ placeholder }) {

  const [valor, setValor] = useState("");
  const [erro, setErro] = useState(false);

  function handleChange(e) {

    const novoValor = e.target.value;

    setValor(novoValor);

    setErro(novoValor.trim() === "");
  }

  return (
    <div className="flex flex-col mb-3">

      <input
        type="text"
        placeholder={placeholder}
        value={valor}
        onChange={handleChange}
        className="w-full px-3 py-2 text-sm border border-gray-300 rounded-md focus:border-blue-600 focus:ring-1 focus:ring-blue-400 outline-none"
      />

      {erro && (
        <p className="text-sm text-red-600 mt-1">
          O campo não pode ficar vazio. ⚠️
        </p>
      )}

    </div>
  );
}
```

No campo encontramos:

```text

```

Nesse caso:

```text

```

define o destaque e:

```text

```

Também utilizamos:

```text

```

Essa classe remove o `outline` padrão do elemento.

No exemplo, o feedback visual do foco passa a ser fornecido pelas classes:

```text
focus:border-blue-600
```

# Estilizando `Button.jsx`

# Responsividade

O Tailwind também possui recursos para aplicar estilos de acordo com diferentes
tamanhos de tela.

Alguns prefixos utilizados para isso são:

```text
sm:
md:
lg:
```

A estrutura geral é:

```text
prefixo:classe
```

Por exemplo:

```text
md:w-80
```

indica que determinada regra está associada ao breakpoint `md`.

Outro exemplo seria:

```text
text-base md:text-lg
```

Temos:

```text
text-base
    │
    └── comportamento inicial

md:text-lg
    │
    └── comportamento a partir do breakpoint md
```

:::info

Neste capítulo, nosso foco principal está nas classes utilitárias utilizadas
pela aplicação de Login.

Os prefixos responsivos `sm:`, `md:` e `lg:` representam uma possibilidade de
evolução da mesma abordagem para diferentes tamanhos de tela.

:::

# Conceitos-chave do Tailwind

Podemos consolidar os principais conceitos trabalhados:

| Conceito | Descrição |
|---|---|
| Utility-First CSS | Estilos construídos pela combinação de classes utilitárias |
| Escala de cores | Classes como `gray-100`, `blue-600` e `green-400` |
| Espaçamento | Utilitários como `p-8`, `px-3`, `py-2` e `mb-4` |
| Flexbox | Utilitários como `flex`, `flex-col`, `justify-center` e `items-center` |
| Estados visuais | Variantes como `hover:` e `focus:` |
| Ring | Destaque visual aplicado principalmente em elementos com foco |
| Transições | Classes como `transition-colors` |
| Responsividade | Prefixos como `sm:`, `md:` e `lg:` |
| Consistência visual | Uso de escalas predefinidas de tamanho, cor e espaçamento |
