# 📘 ReactJS – Estrutura de Projeto, Componentes e Props

## Introdução

O **ReactJS** permite construir interfaces de usuário a partir de **componentes**, ou seja, partes menores da interface que podem ser organizadas, combinadas e reutilizadas na construção de uma aplicação.

Antes de desenvolver aplicações mais complexas, é importante compreender como um projeto ReactJS é estruturado e como seus diferentes arquivos se relacionam.

Neste capítulo, utilizaremos uma aplicação simples de **Login** para explorar a organização básica de um projeto ReactJS e compreender como diferentes componentes podem ser utilizados em conjunto.

Ao longo do exemplo, serão apresentados componentes construídos de duas formas:

- **Componentes de Classe (Class Components)**;
- **Componentes Funcionais (Function Components)**.

Também será apresentado o conceito de **Props (Properties)**, utilizado para transmitir informações entre componentes.

O exemplo permitirá acompanhar o fluxo da aplicação desde o arquivo `index.html` até os componentes responsáveis pela construção da interface.

---------------------

## 🎯 Objetivos de Aprendizagem

Ao concluir este capítulo, você deverá ser capaz de:

- compreender a estrutura básica de um projeto ReactJS;
- identificar o papel do arquivo `index.html`;
- compreender a função do arquivo `main.jsx`;
- identificar o componente raiz `App`;
- compreender o conceito de **componentização**;
- criar e utilizar componentes React;
- diferenciar **Componentes de Classe** e **Componentes Funcionais**;
- compreender a utilização de JSX;
- utilizar fragmentos (`<> </>`) para agrupar elementos;
- compreender o funcionamento de `import` e `export`;
- compreender o conceito de **Props**;
- transmitir informações de um componente pai para um componente filho;
- acessar Props utilizando `this.props` em componentes de classe;
- utilizar desestruturação de Props em componentes funcionais;
- compreender como diferentes componentes podem ser combinados para construir uma interface.

## Estrutura do Projeto ReactJS

Para compreender como os arquivos de uma aplicação ReactJS trabalham em conjunto, considere a estrutura utilizada neste capítulo.

Na raiz do projeto temos o arquivo:

```text
index.html
```

O arquivo `index.html` carrega:

```text
src/main.jsx
```

O arquivo `main.jsx`, por sua vez, utiliza o componente:

```text
src/App.jsx
```

O componente `App.jsx` utiliza o componente:

```text
components/props/Login.jsx
```

Finalmente, `Login.jsx` utiliza outros componentes responsáveis pela construção da interface:

```text
Label.jsx
Labelln.jsx
InputText.jsx
Button.jsx
```

Podemos representar esse fluxo da seguinte maneira:

```text
index.html
    │
    ▼
main.jsx
    │
    ▼
App.jsx
    │
    ▼
Login.jsx
    │
    ├── Label.jsx
    │
    ├── Labelln.jsx
    │
    ├── InputText.jsx
    │
    └── Button.jsx
```

Essa organização demonstra uma das principais características do ReactJS: a construção da interface a partir da **composição de componentes**.

## Do `index.html` aos Componentes

A aplicação começa pelo arquivo:

```text
index.html
```

Nele existe um elemento que servirá como ponto de montagem da aplicação React:

```html
<div id="root"></div>
```

O mesmo arquivo carrega o módulo:

```html
<script type="module" src="/src/main.jsx"></script>
```

A partir desse ponto, o controle da construção da interface passa para os arquivos JavaScript/JSX da aplicação.

O arquivo `main.jsx` inicializa o React e solicita a renderização do componente:

```jsx
<App />
```

O componente `App`, por sua vez, utiliza:

```jsx
<Login />
```

Já o componente `Login` combina componentes menores para construir a interface.

Portanto, existe uma sequência de composição:

```text
HTML
 │
 ▼
React
 │
 ▼
App
 │
 ▼
Login
 │
 ▼
Componentes da Interface
```

## Componentização

Um dos conceitos centrais trabalhados neste capítulo é a **componentização**.

Em vez de construir toda a interface em um único arquivo, podemos dividi-la em partes menores.

No exemplo apresentado, a tela de Login utiliza quatro componentes:

| Componente | Responsabilidade |
|------------|------------------|
| `Label` | Exibir pequenos textos utilizados como rótulos. |
| `Labelln` | Exibir textos utilizados na composição da interface. |
| `InputText` | Criar campos de entrada de texto. |
| `Button` | Criar um botão reutilizável. |

Esses componentes são posteriormente reunidos por:

```text
Login.jsx
```

Assim:

```text
                Login
                  │
        ┌─────────┼─────────┐
        │         │         │
      Label    InputText   Button
        │
     Labelln
```

> O diagrama representa conceitualmente a composição da interface. Os componentes `Label`, `Labelln`, `InputText` e `Button` são utilizados por `Login` para construir a tela.

Essa separação permite que os componentes sejam reutilizados em diferentes partes de uma aplicação.

## Componentes de Classe e Componentes Funcionais

O exemplo também apresenta duas formas de construção de componentes React.

### Componentes de Classe

Os componentes `Label` e `Button` são implementados utilizando classes.

A estrutura básica segue o padrão:

```jsx
class Componente extends React.Component {
    render() {
        return (
            ...
        )
    }
}
```

Nesse modelo, o componente herda de:

```javascript
React.Component
```

e utiliza o método:

```javascript
render()
```

para definir o conteúdo que será apresentado.

### Componentes Funcionais

Os componentes `Labelln`, `InputText`, `Login` e `App` são implementados utilizando funções.

A estrutura básica é:

```jsx
function Componente() {
    return (
        ...
    )
}
```

Nesse caso, uma função JavaScript retorna o JSX que representa a interface do componente.

Ao longo do capítulo, poderemos observar as diferenças entre essas duas formas de implementação.

## Introdução às Props

Além da componentização, o exemplo introduz o conceito de **Props**.

Props são informações transmitidas de um componente para outro.

Considere:

```jsx
<Label texto="Usuário: " />
```

Nesse exemplo, o componente `Label` recebe uma propriedade chamada:

```text
texto
```

com o valor:

```text
Usuário:
```

Outro exemplo aparece no componente `InputText`:

```jsx
<InputText placeholder="user..." />
```

Nesse caso, é transmitida a prop:

```text
placeholder
```

Também podemos transmitir informações ao componente `Button`:

```jsx
<Button valor="Logar" />
```

Portanto:

```text
Componente Pai
      │
      │ Props
      ▼
Componente Filho
```

As Props permitem utilizar um mesmo componente com diferentes informações, favorecendo sua **reutilização**.

## Arquivo `index.html`

O arquivo `index.html` representa o ponto inicial da aplicação no navegador.

Embora a interface seja construída pelos componentes React, ainda é necessário um documento HTML responsável por fornecer a estrutura inicial da página e indicar onde a aplicação será montada.

No projeto utilizado neste capítulo, dois elementos são especialmente importantes:

```html
<div id="root"></div>
```

e:

```html
<script type="module" src="/src/main.jsx"></script>
```

O primeiro define o local no qual a aplicação React será inserida.

O segundo carrega o arquivo `main.jsx`, responsável por iniciar a aplicação.

O fluxo inicial pode ser representado por:

```text
index.html
    │
    ├── <div id="root">
    │        ▲
    │        │ montagem da aplicação
    │
    └── main.jsx
             │
             ▼
           React
```

### **Linhas 09–12 — Corpo da página e inicialização da aplicação**



Inicialmente, o elemento está vazio:

```html

```

Posteriormente, o React localizará esse elemento por meio de seu identificador:

```text

```

O `index.html` disponibiliza o elemento `root`, enquanto `main.jsx` será responsável por iniciar o React e utilizar esse elemento para montar a aplicação.

## O Papel do `root`

O elemento:

```html
<div id="root"></div>
```

estabelece a ligação entre o documento HTML e a aplicação React.

Podemos pensar no `root` como um **ponto de entrada da interface React dentro da página HTML**.

O fluxo pode ser representado da seguinte forma:

```text
index.html
     │
     ▼
<div id="root">
     ▲
     │
     │ React monta a aplicação
     │
main.jsx
     │
     ▼
<App />
```

No próximo arquivo estudado, `main.jsx`, veremos como o React localiza exatamente esse elemento.

---------------------

## O Papel de `type="module"`

A instrução:

```html
<script type="module" src="/src/main.jsx"></script>
```

não apenas carrega um arquivo JavaScript.

O atributo:

```html
type="module"
```

indica que o arquivo será tratado como um módulo.

Isso é importante porque os arquivos utilizados no projeto trabalham com instruções como:

```javascript
import
```

e:

```javascript
export
```

Por exemplo, `main.jsx` poderá importar o componente `App`:

```javascript
import App from './App.jsx'
```

A organização em módulos permite separar a aplicação em diferentes arquivos e estabelecer explicitamente as dependências entre eles.

## Arquivo `main.jsx`

Depois que o navegador carrega o `index.html`, o arquivo `main.jsx` é responsável por **inicializar a aplicação React**.

Na parte anterior, vimos que o `index.html` possui:

```html
<div id="root"></div>
```

e carrega:

```html
<script type="module" src="/src/main.jsx"></script>
```

Agora podemos compreender como `main.jsx` utiliza esse elemento `root` para montar a aplicação.

O fluxo é:

```text
index.html
    │
    ▼
main.jsx
    │
    ├── localiza #root
    │

    │

              │
              ▼

```

```jsx
    </StrictMode>,
```

```text
Button
```

Durante essa construção, foram apresentadas duas formas de implementação de componentes.

`Label` e `Button` foram construídos como **Class Components**, utilizando:

```javascript
extends React.Component
```

e:

```javascript
render()
```

Já `App`, `Login`, `Labelln` e `InputText` foram apresentados como **Function Components**.

Também estudamos **Props**, utilizadas para transmitir informações aos componentes.

Por exemplo:

```jsx
<Label texto="Usuário: " />
```

fornece a Prop `texto` ao componente `Label`.

Em componentes de classe, vimos o acesso utilizando:

```javascript
this.props.texto
```

Nos componentes funcionais apresentados, utilizamos desestruturação:

```javascript
function Labelln({ texto })
```

A reutilização de `Label` e `InputText` com valores diferentes demonstrou como as Props permitem configurar um componente sem alterar sua estrutura.

Assim, o exemplo integrou os conceitos de **estrutura de projeto, JSX, modularização, componentes, composição, reutilização e Props** na construção de uma interface ReactJS.
